## Пока НЕ реализовано / не подтверждено

- Новая комиссия: 100% продавцу / комиссия только на выводе, миграция активных сделок.
  Текущие финансовые правила и тексты 70/30 пока остаются прежними.
- Каталог подарков, подбор сочетаний, NFT threshold, gift payout worker,
  новая модель заявок/расчёта комиссии, admin-уведомления и управление выплатой.
- Публичное сообщение администратора участникам сделки и его новая стилизация.
- Полная история сделок с контекстом товара: вкладка «История» пока переиспользует
  существующую историю операций. Активные карточки уже улучшены.
- Дополнение всех разделов Информации новыми согласованными финансовыми правилами.
- Изменение стиля продвигаемых объявлений.
- Реальная проверка сохранённого игрового ID после Telegram/Railway restart и
  двухаккаунтный end-to-end. Существующие серверные поля не удалялись/не менялись.

## Решение, необходимое до финансовой реализации

При нескольких `sendGift` часть отправок может успешно завершиться до ошибки.
После сетевого timeout результат тоже может быть неизвестен. Полный автоматический
возврат тогда способен выдать покупателю и подарки, и AF; слепой retry — второй подарок.
Нужно согласовать правило частичной/неопределённой выдачи. Предложение: сохранять
резерв до ручной сверки, не повторять неизвестную отправку автоматически и уведомлять
администратора. Возврат допустим лишь для подтверждённо невыданной части после сверки.

Для live-проверки также требуется отдельная тестовая среда/два аккаунта и согласованный
объём настоящих операций. Секреты в чат или frontend не нужны.
