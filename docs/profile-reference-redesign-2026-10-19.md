# Профиль AutoFlow Market — 19.10.2026

## Объём изменения

Переработан существующий экран `profile`, а не отдельный демонстрационный сайт. Макет пользователя воспроизведён настоящими HTML/CSS-компонентами: тёмный фон, AF-монограмма и золотая линия, карточка личности с синим аватаром, отдельный баланс справа, меню в две колонки, фиолетовая строка администратора, компактные объявления. Старая плоская сетка и конкурирующие стили профиля удалены, а не накрыты ещё одной темой.

Фото, имя, username и Telegram ID берутся из `/me`; сумма остаётся `wallet.available_balance`. Объявления, статусы, цены и счётчики — из `/profile`. Данные из референса не добавлены в приложение. Имя сохраняется полностью в DOM и title, но на очень узком экране визуально ограничено тремя строками; длинный username получает многоточие с полным title. Telegram ID копируется полностью через уже существующий Clipboard/fallback.

Сохранена существующая нижняя навигация и её исходные изображения. Небольшие изменения её оформления действуют **только** при `body.profile-open`; остальным разделам они не назначаются. Нативная верхняя панель Telegram не имитируется. Дублирующая плавающая кнопка чата скрыта только в профиле, чтобы не закрывать «Удалить»: тот же раздел и счётчик непрочитанных остаются в «Сделки и чаты», на остальных страницах плавающая кнопка работает как прежде.

## Скриншоты и отличие от референса

`profile-reference-admin-390.png` и `profile-reference-user-320.png` — настоящий рендер текущего приложения на изолированных тестовых данных. Изображения автомобилей и аватар здесь специально помечены тестовыми; это не production-аккаунт и не фиктивные данные в рабочем приложении.

- Сохранены композиция, тёмно-синяя палитра, правый золотой блок AF, две колонки действий и компактные карточки.
- Нет неработающего карандаша редактирования Telegram-аватара.
- Нет нарисованной Telegram-панели. Отступы берутся из существующей Mini App интеграции.
- Кнопки объявлений имеют высоту не менее 44 CSS px; при длинном названии карточка растёт, не обрезая название и не скрывая действия.
- «Проданные товары», история операций/выводов и диалоги не исчезли ради сходства с тремя карточками на картинке.

## Сохранённые действия

| Элемент | Существующий путь |
| --- | --- |
| Пополнение / вывод | `openSecondary('topup' / 'withdraw')`; прежние формы и расчёты |
| Баланс | Существующий `wallet`, история заявок и помощь по заявке |
| Мои объявления | `switchProfileTab('listings')`, активные и проданные |
| Сделки и чаты | Существующий `activity`: активные сделки / история / диалоги |
| Поддержка / информация | `openSupport()`, существующий `help` |
| Администратор | `admin_access.tabs`, прежние `applyRole()` / `openAdminPanel()` и серверная авторизация |
| Изменить / закрепить / удалить | Прежние `editListing()` / `promoteListing()` / `deleteListing()`; удаление только после подтверждения |

В карточке используются первые одна-две настоящие фотографии объявления, с lazy loading и async decode. Для собственного `/api/media/{id}` применяется существующий `?preview=true`; внешние подписанные и старые URL не переписываются. Относительный API base `/api` поддерживается. При недоступном изображении остаётся нейтральный fallback, а не чужая фотография. Ошибка/отсутствие аватара возвращает инициалы.

## Проверки

Локально: **167/167 Node-тестов**, проверка синтаксиса JavaScript, production asset build и `git diff --check` прошли. В проекте нет отдельной настройки TypeScript/ESLint; самостоятельный typecheck/lint не объявляется выполненным.

Новый браузерный набор: обычный пользователь и администратор на **320, 360, 375, 390, 414, 430 px**, плюс сценарий медленного `/profile` с относительным API base и повреждённым историческим URL. Проверяются:

- реальные поля из тестового API, точный баланс, полное копирование ID через Clipboard и fallback;
- отсутствующий/ошибочный аватар, отсутствующий username, длинное имя, баланс 1 234 567 890.12;
- CP1/CP2, действующее VIP, все **17 активных и 2 проданных** объявления, а не только три видимых;
- открытие всех пунктов меню, кошелька, истории, диалогов и админки; подмена видимости кнопки не даёт пользователю вход в админку;
- открытие объявления, формы редактирования, реального окна VIP с отменой, удаления с отменой;
- 44 px tap targets, равные финансовые кнопки в одной строке, отсутствие горизонтального overflow, доступность последней карточки над нижней панелью;
- повторные переходы, отсутствие размножения запросов/обработчиков и отсутствие финансовых/изменяющих объявления команд при открытии/отмене.

Также выполнены старый профильный набор (8 сценариев), `media-help-browser` (4 ширины), `catalog-game-filters-browser` (6 сценариев): прежние каталоги и независимые фильтры КП не сломаны. Полный CI проверяется отдельно перед передачей PR на review; подробные доказательства — в артефакте `publication-browser-evidence`, подпапка `profile-reference`.
