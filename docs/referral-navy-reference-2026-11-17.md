# Реферальная программа — визуальное обновление 17.11.2026

## Изменения

Единственный рабочий код изменений — CSS существующего раздела «Ещё».
Вместо старой фиолетовой темы используются глубокий navy-фон, синеватые
контуры, белый заголовок и оранжевая вторая строка. Убран старый декоративный
круг баннера. Иконка двух пользователей остаётся настоящим SVG внутри
золотистого квадрата.

Блок комиссии и счётчик выровнены в один ряд. Сохранены вертикальный разделитель,
отдельная рамка числа и золотистая иконка — в том числе на 320 px. Три равные
карточки оформлены как на предоставленном скриншоте: navy, тонкая золотистая
рамка с боковыми вырезами, иконка, количество друзей, сумма AF, статус и стрелка.
Отступы, высота и типографика адаптированы для небольших экранов.

Ссылки, копирование, «Переслать», окно подробностей и полученные награды
сохранены; нижняя часть только перекрашена в ту же палитру. Переход по карточке
по-прежнему открывает информационное окно, а не ручное начисление.

Общая шапка (включая существующий баннер), аватар, имя, баланс и нижняя навигация
не переделывались. Скриншот используется как образец **реферального блока**;
нативная панель Telegram не имитируется. Другие разделы не получают эту тему.

## Не изменено

- `referrals.js` / `app.js`, маршрутизация, обработчики и Telegram share flow.
- Серверный API, индивидуальный URL, подсчёт приглашений и `canInvite`.
- Условия 3/10/20, суммы наград, подтверждённый статус, 5% и баланс.
- БД, миграции, платежи, публикация и продажа товаров.

Новых API, env, зависимостей или миграций нет. В рабочем интерфейсе нет
демонстрационных данных; тестовые API/Telegram transport используются только
в браузерных тестах. `index.html` изменён только для content-derived build hash.

## Проверки

- Все 232 существующих Node-теста проходят.
- Браузерные сценарии на 320/375/390/430 px: реальные компоненты и CSS,
  тестовые ответы API, 0/1/2/3/8/10/17/20/25 приглашений, ожидаемые/полученные
  награды, копирование полного URL, Clipboard fallback/error, native share
  callback/cancel/error, перезагрузка и 80 переключений разделов.
- Slow/error/retry на 390 px; нормальная прокрутка и закрытие окна всеми
  существующими способами; reduced-motion.
- Добавлены небольшие проверки navy-палитры, выравнивания двух блоков,
  видимой иконки на 320 px и отсутствия обрезания текста/сумм внутри карточек.
- Повторно запускаются Node syntax checks, сборка статических ресурсов и
  `git diff --check`. Полный CI, включая существующий production-image build,
  проверяется перед передачей PR; окончательный результат указан в PR.

Скриншоты реального рендера на **тестовых данных** сохраняются существующим
браузерным набором в CI artifact `publication-browser-evidence`, каталог
`referral-reference`. Файлы `referral-navy-section-{width}.png` показывают только
обновлённую область; полные изображения сохраняют неизменённую шапку и навигацию.

Физические iPhone/Android и реальная отправка сообщения в Telegram не
проверялись; mobile/touch Chromium не выдаётся за тест на телефоне.
Production-данные и деньги не изменялись. Автоматического Deploy/слияния нет.

## Файлы / rollback

`webapp/css/style.css`, build fingerprint в `webapp/index.html`, небольшие
UI-regressions в `webapp/tests/referral-reference-browser.cjs` и этот отчёт.
Rollback — возврат frontend-коммита и обычная пересборка статических ресурсов;
откат БД не нужен.
